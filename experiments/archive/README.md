# Historical experiment code

Original experiments were moved here on 2026-10-04 without deleting source files.
See [the experiment catalog](../README.md) for their roles. These are preserved
research implementations, not frozen exclusive NeurIPS or ICML releases: shared
libraries evolved across submissions. Exact submission recipes belong to their
recorded commits/configurations, not to the date of a whole source directory.

Original `experiments/<folder>` paths remain relative compatibility symlinks.
The early decimal and fixed-C1 tasks stay next to each other because they share
helpers. No current core benchmark package was relocated.
